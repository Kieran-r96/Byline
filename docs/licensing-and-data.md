# Licensing, data and IP notes

Last audited 2026-10-24 (`docs/security-audit.md`, section "Licences").

- **Data:** 100% synthetic, generated by `apps/api/byline/simulation` from fixed seeds. There is no real league, club, player, official or broadcast data. This meets the official rules' requirement that "Projects must use synthetic, football-realistic data" (§4.7).
- **Clubs and people:** Northbridge Athletic and Riverton City, their crests and kits, players, managers, officials, stadiums, honours and histories are invented for BYLINE. Facts are labelled `fictional_seeded`, with source "BYLINE fictional seed v1". Any resemblance to real people or clubs is unintended. The agent validator rejects drafts that mention a real league or data provider.
- **Crests and brand:** the crests, wordmark and favicon are original SVGs drawn for this project. No Premier League marks, club badges, player images, footage, crowd audio or music are used. The 3D stage's textures are generated on a canvas at runtime; the web app contains no image, video, audio or 3D model files besides the favicon.
- **Screenshots:** `docs/screenshots/` holds screenshots of BYLINE itself only.
- **Laws of the Game:** short paraphrases of IFAB Laws 2026/27 points, linked to theifab.com. The IFAB text is authoritative, and BYLINE does not reproduce the Laws.
- **Fonts:** Instrument Sans, Archivo, Manrope and Barlow Condensed, all SIL Open Font License 1.1, self-hosted from @fontsource packages (no font CDN). Copyright holders and use: `apps/web/THIRD_PARTY.md`.
- **Bundled web libraries:** React, React DOM, scheduler, three.js and zod (all MIT). Their licence texts and the fonts' OFL texts ship with the built app at `/third-party-notices.txt` (`apps/web/public/third-party-notices.txt`).
- **Python runtime dependencies** (45 distributions in the API image's closure, checked from installed metadata): MIT, BSD-3-Clause, Apache-2.0, PSF-2.0, MIT-0, and MPL-2.0 for `certifi` (CA bundle, unmodified). Top level: FastAPI, Starlette, Uvicorn, Pydantic, pydantic-settings, Microsoft Agent Framework (MIT), OpenAI Python SDK (Apache-2.0), azure-identity and MSAL (MIT).
- **Dev and build tools** (not shipped): see `apps/web/THIRD_PARTY.md`; all permissive, plus MPL-2.0 (axe-core, lightningcss, unmodified) and CC-BY-4.0 (caniuse-lite data).
- **No gambling:** there are no odds, betting links or wagering language. The agent validator blocks betting terms.
- **Project licence:** no LICENSE file is included. All rights are reserved; the code is published for evaluation, apart from the rights the competition's official rules grant the Promotion Entities (§7).
