## 4. Findings

- Publication is binary and late: median first signal 24.15 min, median longest silence 36.6 min (worst 72.2 min). Nothing shows a pattern while it builds.
- Developing stage is measurable without lowering any gate: with the danger requirement removed, the channel detector finds the same authored patterns 0.5-3.0 min earlier and recovers none it misses. V1 shows that state as DEVELOPING (measured counts only, no story claim) and promotes it when the production gates pass.
- Gates that must stay: tail probability 0.005 -> 0.05 adds 26 candidates, only 1 on authored patterns; max seconds 12 -> 18 adds 30 candidates, only 0 on authored patterns; min advance 30 -> 20 m adds 13 candidates, only 2 on authored patterns. Relaxing them would mostly publish noise.
- Cooldowns hide almost nothing here (at most one extra), so a storyline should version the existing story rather than add new ones.
- Agent time: the investigator is 54% of a full investigation's latency (two model calls with tool round-trips); analyst and verifier are about 4 s each. V3 should profile the investigator first and keep the verifier and rule check intact.
- Only 3 of the golden match's 6 candidates have real AI runs; the rest are detector summaries. V2 tiers make that explicit per storyline version.
